Research · Feb 2026 – Present

HTM Spatial Pooler accelerator

Undergraduate Research Assistant, RTL Design & Verification. Nano Computing Research Group, University of South Florida, Tampa, FL.

Tools

  • SystemVerilog
  • SVA
  • AXI4-Stream
  • Vivado
  • Python
  • AMD Kria KV260

Verify

10M+ stimulus cycles, bit-exact

Verified a 2048-column HTM Spatial Pooler accelerator bit-exact against a Python golden model, using a self-checking SystemVerilog testbench that flags mismatches at cycle granularity.

Timing

200 MHz zero violations on AMD Kria KV260

Closed timing with Vivado synthesis and static timing analysis, and signed off every AXI4-Stream interface with SVA checkers for tvalid/tready stability and tlast framing.

Debug

60% less debug time on pipeline failures

Correlated assertion failure traces with on-chip event counters to root-cause a bad FSM transition.

Result

9 µs per inference

The fixed design runs 28× faster than software on the ARM Cortex-A53.

Project · Jan 2025 – May 2025

RISC-V SoC with 8×8 systolic-array accelerator

A PicoRV32 RISC-V SoC with a memory-mapped accelerator, verified with assertions before FPGA bring-up on Spartan-7.

Tools

  • SystemVerilog
  • SVA
  • C
  • AXI4
  • Questa

Assert

30+ SVA properties

Properties on AXI4 handshakes, FIFO overflow/underflow, and PE-array boundaries exposed 4 control-FSM bugs that random simulation missed.

Stimulus

Abstract PE-array model

Constraining stimulus with the model hit corner-case FSM states that unconstrained random runs missed.

Measure

12× over CPU-only, at 100 MHz on Spartan-7

Measured with self-checking bare-metal C tests that drive the accelerator through memory-mapped loads and stores and report pass/fail over UART.

Project · Sep 2026 – Oct 2026

UVM testbench for an AXI4 DMA controller

A UVM environment that checks every transfer against a C reference model.

Tools

  • UVM
  • SystemVerilog
  • C
  • Python
  • TCL

Env

AXI4 agents, RAL model, scoreboard

Every transfer is checked against a C reference model through DPI-C, with SVA checkers bound to the bus so protocol errors fail on the exact cycle.

Coverage

92% functional coverage over 400 seeds

Constrained-random over burst length, unaligned addresses, 4KB crossings, and back-pressure. Exposed 3 RTL bugs, including a dropped last beat on unaligned bursts.

Regress

Automated regression

Python/TCL scripts run seeds in parallel, merge coverage, and bucket log failures by signature.

Project · 2026

Pipelined fixed-point datapath (Black-Scholes pricer)

A fixed-point datapath that replaces exp, log, sqrt, and the normal CDF with lookup tables and polynomials.

Tools

  • SystemVerilog
  • C++
  • Python
  • Verilator
  • Vivado

Pipeline

250 MHz one result per clock

Fixed 64-cycle latency, bit-exact to a C++ model in Verilator.

Width

25 bits chosen from an 18 to 32 bit sweep

A Python design-space script swept word width; 25 bits was the narrowest that held error under 2×10−5.

PPA

−31% DSP area, with −22% estimated power

Both compared with a 32-bit build.
