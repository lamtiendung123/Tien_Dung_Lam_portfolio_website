# Product: engineering and research portfolio

## Audience
Digital IC/RTL/design verification and FPGA recruiters; computer architecture/accelerator and neuromorphic computing researchers; engineering collaborators.

## Product promise
In 20 seconds a visitor should understand **what hardware problems this engineer works on**, what was actually built and measured, and where to inspect source, diagrams, results, or research context.

## Narrative
- Positioning: computer engineering; digital hardware design, verification, FPGA acceleration, CMOS-VLSI and research computing.
- Tone: grounded, precise, intellectually curious. First-person; no motivational filler, hyperbole or invented awards.
- Default hierarchy: Home/overview → Selected Work → Research → Skills/Toolchain → Experience/education → Contact.
- Possible featured work (verify owner approval, accuracy, permissions and links before publication): low-latency FPGA pipeline on Kria KV260; fixed-point options-pricing accelerator; RISC-V PicoRV32 SoC with UART; CMOS standard-cell/layout work; HTM/neuromorphic exploration.
- Project cards must tell visitors **problem / contribution / implementation / verification / measured result or limitation**, with a link to evidence where legally publishable.

## Scope
MVP is a static, fast and accessible web portfolio. Do not add a public chatbot, secret-bearing API, accounts, admin panel, analytics, contact database or server without a new spec and authorization.

## Source-of-truth
Public claims require evidence from the owner and `docs/CONTENT_EVIDENCE.md`. Existing social handles and project titles can be proposed, not assumed safe to publish beyond the GitHub link the owner gave.
